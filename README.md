# 📈 Cryptocurrency Price Forecasting using Python

This project focuses on analyzing and forecasting cryptocurrency prices using historical market data fetched dynamically with the **yfinance** library.  
The goal is to understand price trends and build a basic forecasting approach using Python.

---

## 🔍 Project Overview

- Live cryptocurrency data is fetched directly from Yahoo Finance
- No separate dataset file is used
- Data is analyzed and visualized using Python libraries
- Helps understand market trends and future price movement patterns

---

## 🧠 Technologies & Libraries Used

- Python
- Jupyter Notebook
- yfinance
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn (if used for forecasting)

---

## 📊 Data Source

- **Yahoo Finance**
- Data is fetched in real-time using the `yfinance` Python library  
- Example assets: Bitcoin (BTC), Ethereum (ETH), etc.

> Note: Since data is fetched dynamically, no CSV or Excel dataset is included in this repository.

---

## ⚙️ How the Project Works

1. Import required Python libraries
2. Fetch cryptocurrency price data using `yfinance`
3. Perform data cleaning and preprocessing
4. Visualize price trends
5. Apply forecasting logic (moving average / regression / ML model if used)
6. Analyze results

---

## ▶️ How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/CryptoCurrency-Price-Forecasting.git
   ```
2. Open the project folder
3. Install required libraries:
```bash
pip install yfinance pandas numpy matplotlib seaborn scikit-learn
```
4. Open the notebook:
```bash
jupyter notebook CryptoCurrency_Price_Forcasting.ipynb
```
5. Run all cells step by step
